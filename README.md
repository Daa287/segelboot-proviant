# ⚓ Segelboot Proviant App v5.2

Eine maritime Proviant- und Inventar-App für Segelboote.

## Features
- 📦 Inventar mit Fotos, Barcode-Scanner, Quick-Add
- 🛒 Einkaufsliste mit automatischen Warnungen  
- 🍽️ Mahlzeitenplaner mit Rezepten
- 🗂️ Stauraum-Verwaltung (Kühlbox, Bilge, Cockpit, Salon...)
- 📊 Statistik-Dashboard
- 🗓️ Reiseplanung mit Bedarfsberechnung
- 🆘 Notfall-Reserve (Havarie +3 Tage)
- 🎣 Fischfang-Log
- 💰 Kosten-Tracker mit Hafen-Einkauf
- 🖨️ PDF-Packliste drucken
- 🌙 Dark/Light Mode
- 🌍 Deutsch / English / Español
- 💾 Backup Export/Import (JSON, CSV, TXT)

## Installation
Einfach `index.html` im Browser öffnen — keine Installation nötig!

Für GitHub Pages: Settings → Pages → Branch: main → Save

## Offline-Nutzung
Die App speichert alle Daten lokal im Browser (localStorage).  
Kein Internet erforderlich nach dem ersten Laden.
